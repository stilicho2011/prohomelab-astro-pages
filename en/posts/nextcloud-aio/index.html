    What Nextcloud Is

    Nextcloud is a well-known open-source platform for running your own cloud storage and collaboration setup. It handles files, documents, and photos, syncs everything across your devices, and comes with a bunch of built-in services on top:

    • calendar and tasks;
    • video calls (Nextcloud Talk);
    • office documents (Nextcloud Office / Collabora);
    • notes and real-time collaborative editing.

    People often describe Nextcloud as a self-hosted stand-in for Google Workspace or Microsoft 365 - one that's entirely yours to control, running on your own server, with zero dependence on anyone else's cloud.

    What Nextcloud AIO Is

    Nextcloud AIO (All-in-One) is the official build the Nextcloud team itself puts out specifically to make installing and updating as painless as possible.

    A classic install has you hand-configuring Apache/Nginx, PHP, Redis, MariaDB, and cron jobs one by one. AIO skips all of that by running on Docker and bundling everything into its own containers:

    • Nextcloud (the web interface);
    • PostgreSQL (the database);
    • Redis (caching);
    • Collabora Online (document editing);
    • OnlyOffice (optional);
    • a backup container (automatic backups).

    The real selling point of AIO is that every component updates itself automatically, and you can have a fully working cloud running in just a few minutes. It's a great fit for home servers, LXC containers on Proxmox, or a VPS - anywhere simplicity and stability matter more than fine-grained control.

    When You'd Actually Want Nextcloud AIO

    When you want Nextcloud up and running fast, with as little manual configuration of individual pieces as possible.

    What You'll Need First

    Before diving in, make sure you've got:

    • Docker and Docker Compose (2.0+);
    • a server with at least 2 GB of RAM;
    • a domain name with HTTPS access (ideally through Traefik, Caddy, or Nginx Proxy Manager).

    Walking Through My Compose File

    Nextcloud AIO

    Container: nextcloud-aio-mastercontainer

    Don't touch the container_name or the nextcloud_aio_mastercontainer volume name - the built-in backup depends on both staying exactly as they are.

    Ports: 8087:8080 puts the web interface at http://host:8087. Everything else is commented out, which is exactly what you want once a reverse proxy is in the picture.

    On the environment variables: NEXTCLOUD_DATADIR: /media/nextcloud paired with NEXTCLOUD_MOUNT: /media makes sure both Nextcloud and go-vod are looking at the same directory. APACHE_PORT and APACHE_IP_BINDING are set up for the reverse proxy. I've also added imagemagick and imagick via NEXTCLOUD_ADDITIONAL_APKS/NEXTCLOUD_ADDITIONAL_PHP_EXTENSIONS, which come in handy for image processing.

    go-vod

    It depends on Nextcloud AIO coming up first (depends_on), and it's set up to use an NVIDIA GPU (runtime: nvidia plus NVIDIA_VISIBLE_DEVICES=all).

    The /media/nextcloud:/mnt/ncdata:ro mount is read-only on purpose, so go-vod can process Nextcloud's files without any chance of accidentally touching them. Just make sure NEXTCLOUD_HOST=https://next.domain.ru actually points at your real Nextcloud domain.

    Networking

    Both containers sit on the external nextcloud network, which lets them talk to each other by container name.

    Volumes

    nextcloud_aio_mastercontainer is critical for the built-in backup - leave it alone. Everything else Nextcloud stores lives under NEXTCLOUD_DATADIR.

    A Few Things Worth Double-Checking

    GPU access for go-vod: make sure the NVIDIA driver and nvidia-container-toolkit are actually installed on the host, and confirm the container can see the GPU.

    Directory permissions: /media/nextcloud needs to be reachable by both AIO and go-vod. For go-vod specifically, mounting it :ro (read-only) is the safe move.

    Reverse proxy: since ports 80/443 are commented out, you'll need an external reverse proxy - Nginx, Caddy, or Traefik - handling traffic. Make sure it's actually forwarding to APACHE_PORT = 11000.

    Backups: don't mess with the nextcloud_aio_mastercontainer volume, and you can check on your backups directly through the AIO interface.

    Wrapping Up

    Nextcloud AIO is about as close as you'll get to spinning up a full-featured cloud with one click. It combines the convenience of Docker, hands-off updates, and the backing of the Nextcloud team's own official support. It's a natural fit for a home server, an LXC container on Proxmox, or a VPS - anywhere simplicity, security, and self-sufficiency actually matter. If you'd rather have full control over the stack without Docker, check out the alternative install method in Nextcloud in an LXC.
